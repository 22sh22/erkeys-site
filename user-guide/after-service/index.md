# A/S 문의 안내

MODU-C 사용 중 문제가 생겼다면 아래 순서대로 확인해 주세요.

확인 가능한 내용을 함께 보내주시면 증상을 다시 묻는 시간을 줄이고 더 정확하게 안내할 수 있습니다.

## 먼저 사용을 멈춰야 하는 경우

아래 증상이 있으면 제품 사용과 충전을 중단해 주세요.

- 제품이나 배터리 부위가 비정상적으로 뜨거움
- 타는 냄새 또는 연기
- 배터리가 부풀어 오른 것으로 보임
- 액체가 들어감
- 케이블이나 단자가 녹거나 심하게 손상됨

케이블을 분리하고, 제품을 누르거나 직접 분해하지 마세요. 안전한 곳에 둔 뒤 증상을 확인할 수 있는 사진과 함께 문의해 주세요.

## 문의 전 기본 확인

안전과 관련된 증상이 아니라면 아래 항목만 먼저 확인해 주세요.

1. 키보드를 충분히 충전합니다.
2. 충전이나 케이블 관련 증상이라면 다른 케이블과 USB 포트에서도 확인합니다.
3. 사용 중인 기기를 재부팅합니다.
4. 블루투스 문제라면 기존 등록을 삭제하고 다시 연결합니다.
5. 가능하면 다른 PC나 휴대폰에서도 같은 증상이 생기는지 확인합니다.
6. 문제가 생기는 키, 부위, 연결 방식을 기록합니다.

전체 초기화, 펌웨어 변경, 제품 분해는 공식 안내를 받기 전에 진행하지 않는 것을 권합니다.

## 문의할 때 필요한 정보

### 주문 정보

- 구매자명
- 구매처
- 주문번호 또는 주문을 확인할 수 있는 정보
- 제품을 받은 시기

### 사용 환경

- 연결한 기기
- 운영체제
- 사용 중인 연결 방식
- 사용 중인 케이블이나 허브

### 증상

- 문제가 생기는 키 또는 부위
- 처음 발생한 시점
- 항상 발생하는지, 가끔 발생하는지
- 어떤 순서로 조작하면 문제가 다시 생기는지
- 이미 시도한 방법
- 충격, 침수, 임의 분해 또는 설정 변경 여부

정보가 일부 없어도 문의할 수 있습니다. 확인할 수 없는 항목은 `확인하지 못함`이라고 적어주세요.

## 사진과 영상 촬영 방법

사진이나 영상에는 아래 내용이 보이면 좋습니다.

- 제품 전체 모습
- 문제가 있는 부위의 가까운 모습
- 케이블과 연결 상태
- 키를 눌렀을 때 화면에 나타나는 입력 결과
- 문제가 반복되는 과정을 처음부터 끝까지 촬영한 짧은 영상

영상은 길게 설명하기보다, 문제가 다시 생기는 조작과 결과가 함께 보이도록 촬영해 주세요.

## 문의 내용 예시

> 구매자명:  
> 구매처와 주문 정보:  
> 사용 기기와 운영체제:  
> 연결 방식:  
> 문제가 있는 위치:  
> 증상이 시작된 시점:  
> 증상을 다시 만드는 순서:  
> 이미 시도한 방법:  
> 사진 또는 영상: 첨부 / 없음

이 양식을 그대로 사용하지 않아도 됩니다. 같은 내용을 알아볼 수 있게 보내주시면 됩니다.

## 접수 후 진행

1. 주문 정보와 증상을 확인합니다.
2. 추가 확인이 필요하면 사진, 영상 또는 간단한 테스트를 요청드립니다.
3. 원인을 확인한 뒤 가능한 조치 방법을 안내합니다.
4. 제품 회수가 필요한 경우 발송 방법과 주의사항을 별도로 안내합니다.

보증 범위, 비용, 처리 기간은 제품 상태와 구매 정보 확인 후 안내드립니다. 확인 전에 무상 처리나 완료 일정을 단정해서 안내하지 않습니다.

## 자주 묻는 질문

### 먼저 제품을 보내면 되나요?

아닙니다. 접수 확인 없이 먼저 보내면 주문자와 증상 확인이 늦어질 수 있습니다. 회수가 필요하다는 안내를 받은 뒤 발송해 주세요.

### 직접 분해하거나 스위치를 빼도 되나요?

문제 부위를 정확히 확인하기 전에는 권하지 않습니다. 먼저 사진이나 영상을 보내고 안내받은 범위에서 확인해 주세요.

### 침수된 제품을 다시 켜봐도 되나요?

전원을 켜거나 충전하지 마세요. 케이블을 분리하고 액체가 들어간 위치와 시점을 기록한 뒤 문의해 주세요.

### 처리 기간은 얼마나 걸리나요?

증상, 부품 상태, 회수 필요 여부에 따라 달라집니다. 제품과 주문 정보를 확인한 뒤 예상 순서를 안내드립니다.

문의는 사이트 하단의 **연락하기**를 이용해 주세요. 공식 접수 링크가 별도로 안내된 경우에는 해당 링크를 이용해 주세요.
