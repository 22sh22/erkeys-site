# A/S 문의 안내

MODU-C 사용 중 문제가 생겼다면 아래 내용을 확인한 뒤 문의해 주세요.

문의 전에 먼저 [A/S 문의 전 자가 확인](/user-guide/after-service/self-check/)을 확인하면 더 빠르게 원인을 좁힐 수 있습니다.

## 먼저 사용을 멈춰야 하는 경우

아래 증상이 있으면 제품 사용과 충전을 중단해 주세요.

- 제품이나 배터리 부위가 비정상적으로 뜨거움
- 타는 냄새 또는 연기
- 배터리가 부풀어 오른 것으로 보임
- 액체가 들어감
- 케이블이나 단자가 녹거나 심하게 손상됨

케이블을 분리하고, 제품을 누르거나 직접 분해하지 않은 상태로 문의해 주세요.

## 문의 전 확인

안전과 관련된 증상이 아니라면 아래 내용만 먼저 확인해 주세요.

- 키보드를 충분히 충전했는지
- 다른 케이블이나 USB 포트에서도 같은지
- 다른 PC나 휴대폰에서도 같은 증상이 생기는지
- 블루투스 문제라면 기존 등록을 삭제한 뒤 다시 연결해 봤는지
- 문제가 생기는 키, 부위, 연결 방식이 무엇인지

전체 초기화, 펌웨어 변경, 제품 분해는 안내를 받기 전에는 권하지 않습니다.

## 문의할 때 보내면 좋은 정보

- 구매처와 주문 정보
- 사용 중인 기기와 운영체제
- 사용 중인 연결 방식
- 문제가 생기는 키 또는 부위
- 증상이 처음 발생한 시점
- 이미 시도한 방법
- 증상을 확인할 수 있는 사진 또는 짧은 영상

정보를 모두 준비하지 못해도 괜찮습니다. 확인할 수 있는 내용만 먼저 보내주세요.

## 보내기 전 주의

제품을 먼저 발송하거나 직접 분해하지 말고, 사이트 하단의 **연락하기**로 먼저 문의해 주세요.
