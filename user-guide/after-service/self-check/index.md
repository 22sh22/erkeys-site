# A/S 문의 전 자가 확인

문의 전에 아래 항목을 확인해 주세요.

## 연결 문제라면

- 사용하려는 연결 방식이 무엇인지 확인합니다.
- 전원 상태가 연결 방식에 맞는지 확인합니다.
- PC 연결용 USB 포트를 사용했는지 확인합니다.
- 기존 블루투스 등록을 삭제한 뒤 다시 연결해 봅니다.

## 입력 문제라면

- [기본 키 설정 및 사용법](/user-guide/key-settings/)에서 키 위치를 확인합니다.
- [MODU-C 키 테스트](/key-test/)에서 입력이 감지되는지 확인합니다.
- 특정 키만 문제인지, 전체 입력이 문제인지 확인합니다.

## 문의할 때 보내면 좋은 정보

- 사용 중인 연결 방식
- PC 또는 기기 종류
- 현재 LED 색상과 깜빡임 여부
- 연결한 USB 포트 위치
- 문제가 생기는 키 또는 부위
- 가능하다면 사진 또는 짧은 영상

모든 정보를 준비하지 못해도 괜찮습니다. 확인 가능한 내용만 먼저 보내주세요.
