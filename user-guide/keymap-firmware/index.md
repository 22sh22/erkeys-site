# 키매핑 및 펌웨어 제작

키매핑을 직접 수정하려면 ZMK 개발 환경에 대한 이해가 필요합니다.

직접 수정 가이드를 준비하기 전까지는 원하는 키배열을 요청해 주세요. 시간이 허락할 때마다 적용한 펌웨어 파일을 업로드하겠습니다.

원본 ZMK 소스: [https://github.com/22sh22/modu-c-firmware](https://github.com/22sh22/modu-c-firmware)
