# MODU-C 사용 가이드

이미 MODU-C를 받은 사용자가 연결과 기본 동작을 직접 확인할 수 있도록 정리했습니다.

아래에서 현재 겪고 있는 문제와 가장 가까운 항목을 선택해 주세요.

## 무엇을 확인해야 하나요?

### 블루투스 연결이 되지 않거나 자주 끊깁니다

[블루투스·무선 연결 방법](/user-guide/bluetooth-wireless/)에서 처음 연결하는 순서와 재연결 방법을 확인해 주세요.

### 키 위치나 동작을 모르겠습니다

[기본 키 설정 및 사용법](/user-guide/key-settings/)에서 키맵을 읽는 방법과 입력 확인 순서를 안내합니다.

### 충전, 입력, 부품 상태에 문제가 있습니다

[A/S 문의 안내](/user-guide/after-service/)에서 문의 전에 확인할 내용과 준비할 정보를 확인해 주세요.

## 처음 사용할 때

1. 제품과 함께 받은 키맵 또는 안내 자료가 있다면 먼저 준비합니다.
2. 유선 또는 블루투스 중 사용할 연결 방식을 선택합니다.
3. 메모장처럼 글자를 입력할 수 있는 화면에서 기본 입력을 확인합니다.
4. 문제가 있으면 연결 방식, 사용 기기, 운영체제, 문제가 생기는 키를 기록합니다.
5. 안내된 순서대로 확인한 뒤에도 해결되지 않을 때 A/S를 문의합니다.

## 문의 전에 준비하면 좋은 정보

아래 내용을 함께 보내주시면 같은 질문을 주고받는 시간을 줄일 수 있습니다.

- 구매자명과 구매처
- 제품명과 주문 정보
- 연결한 기기와 운영체제
- 유선 또는 블루투스 연결 여부
- 문제가 생기는 키나 부위
- 문제가 처음 발생한 시점
- 이미 시도한 방법
- 증상을 확인할 수 있는 사진 또는 짧은 영상

모든 정보를 완벽하게 준비할 필요는 없습니다. 확인할 수 있는 내용만 먼저 보내주세요.

## 바로 사용을 멈춰야 하는 경우

제품이 비정상적으로 뜨겁거나, 타는 냄새가 나거나, 배터리가 부풀어 오른 것으로 보이면 사용과 충전을 중단해 주세요.

케이블을 분리하고 제품을 눌러보거나 직접 분해하지 않은 상태로 [A/S 문의 안내](/user-guide/after-service/)를 확인해 주세요.
