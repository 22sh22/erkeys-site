# MODU-C 사용 가이드

MODU-C를 처음 사용하거나 문제가 생겼을 때 확인할 수 있는 간단한 안내입니다.

## 안내 목록

- [블루투스·무선 연결 방법](/user-guide/bluetooth-wireless/)  
  처음 연결하거나, 등록된 기기와 다시 연결되지 않을 때 확인합니다.

- [기본 키 설정 및 사용법](/user-guide/key-settings/)  
  키 위치, 레이어, 짧게 누르기와 길게 누르기 같은 기본 동작을 확인합니다.

- [A/S 문의 안내](/user-guide/after-service/)  
  충전, 입력, 부품 상태에 문제가 있을 때 문의 전 확인할 내용을 봅니다.

## 처음이라면

먼저 제품과 함께 받은 키맵 또는 안내 자료를 준비해 주세요. 어떤 문서를 봐야 할지 모르겠다면 위 목록에서 현재 상황과 가장 가까운 항목을 선택하면 됩니다.

## 문의가 필요할 때

문서를 확인한 뒤에도 해결되지 않으면 사이트 하단의 **연락하기**를 이용해 주세요. 문제가 생기는 상황, 사용 기기, 연결 방식, 사진이나 짧은 영상을 함께 보내주시면 확인이 빠릅니다.
