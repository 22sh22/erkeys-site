# USB 포트 역할

연결이 되지 않을 때는 먼저 PC와 연결한 USB 포트 위치를 확인해 주세요.

현재 사용 가이드에서 PC 입력용으로 안내하는 포트는 **좌측 키보드의 바깥쪽 USB 포트**입니다.

| 연결 방식 | PC와 연결할 곳 | 확인할 상태 |
| --- | --- | --- |
| 완전히 무선 | 연결하지 않음 | PC와 연결된 케이블을 모두 분리 |
| 한쪽 유선 | 좌측 바깥쪽 USB 포트 | 좌측 LED가 흰색으로 켜짐 |
| 완전히 유선 | 좌측 키보드 USB 포트 | 좌우 모두 유선 split용 펌웨어 상태 |

PC 연결용 포트가 아닌 곳에 케이블을 꽂으면 정상적으로 입력되지 않을 수 있습니다.

펌웨어 교체나 리셋을 위해 `MODU_BOOT` 드라이브에 들어가야 하는 경우에는 [리셋 및 펌웨어 교체](/user-guide/reset-firmware/)를 확인해 주세요.
