# USB 포트 역할

MODU-C는 연결 방식에 따라 사용해야 하는 USB 포트가 다를 수 있습니다.

연결이 되지 않을 때는 먼저 어느 포트를 PC와 연결했는지 확인해 주세요.

| 위치 | 역할 | 사용 상황 |
| --- | --- | --- |
| 좌측 바깥쪽 USB 포트 | PC 연결용 | 한쪽 유선으로 사용할 때 PC와 연결 |
| 좌측 안쪽 USB 포트 | 확인 필요 | 역할 확인 후 작성 |
| 우측 USB 포트 | 확인 필요 | 역할 확인 후 작성 |

PC 연결용 포트가 아닌 곳에 케이블을 꽂으면 정상적으로 입력되지 않을 수 있습니다.

## 연결 방식별 확인

- 완전히 무선으로 사용할 때는 PC와 연결된 케이블을 분리합니다.
- 한쪽 유선으로 사용할 때는 좌측 바깥쪽 USB 포트를 PC와 연결합니다.
- 완전히 유선으로 사용할 때는 정확한 포트 기준 확인 후 정리합니다.
