# USB 포트 역할

바깥쪽 USB-C 포트는 PC와 연결하거나, 펌웨어를 넣을 때 사용합니다.

안쪽 USB-C 포트는 오직 전원을 전달하기 위해 사용합니다.


|  | 좌측 키보드 | 우측 키보드 |
| --- | --- | --- |
| 바깥쪽 | PC와 연결 | 평소 사용하지 않음. 펌웨어 입력용 |
| 안쪽 | 우측으로 PC 전원 전달 | 우측으로부터 전원 공급 |

※주의: MODU-C는 충전식 배터리를 사용하지 않습니다. 종종 발생하는 배터리 부족 경고는 무시해 주세요.
