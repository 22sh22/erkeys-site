# 알려진 문제와 해결 방법

반복되는 증상과 먼저 확인할 내용을 정리하는 페이지입니다.

아직 증상별 하위 페이지를 많이 만들지 않고, 자주 반복되는 문제만 이곳에 모읍니다.

| 증상 | 먼저 확인할 것 | 관련 안내 |
| --- | --- | --- |
| 무선 연결이 되지 않음 | 전원, 배터리, 기존 블루투스 등록 삭제 | [완전히 무선으로 연결하기](/user-guide/connection/wireless/) |
| 우측 키보드가 입력되지 않음 | 우측 LED가 파란 불인지 확인 | [유·무선 연결 방법](/user-guide/connection/) |
| 유선 연결이 되지 않음 | 케이블, PC USB 포트, MODU-C USB 포트 위치 확인 | [USB 포트 역할](/user-guide/usb-ports/) |
| 키 입력이 예상과 다름 | 기본 키맵과 Lower 레이어 확인 | [기본 키 설정 및 사용법](/user-guide/key-settings/) |

## 문의 전 확인

위 내용을 확인해도 해결되지 않으면 [A/S 문의 안내](/user-guide/after-service/)를 확인해 주세요.

문의할 때는 현재 LED 상태, 연결 방식, 사용 중인 기기, 막힌 단계를 함께 보내주시면 좋습니다.
