# 기본 키 설정 및 사용법

MODU-C의 키 위치와 동작은 출고 시 적용된 키맵을 기준으로 확인해야 합니다.

제품과 함께 받은 키맵 이미지나 안내 자료가 있다면 옆에 띄워두고 아래 순서대로 확인해 주세요.

## 키맵을 보는 방법

### 기본 키

키를 짧게 한 번 눌렀을 때 입력되는 문자나 기능입니다.

### 레이어 키

키 수가 적은 키보드는 한 키에 여러 기능을 배치할 수 있습니다. 키맵에 레이어가 표시되어 있다면 해당 레이어 키를 누르는 동안 다른 키의 동작이 바뀝니다.

### 짧게 누르기와 길게 누르기

키맵에 한 키의 기능이 두 가지로 표시되어 있다면 누르는 시간에 따라 동작이 달라질 수 있습니다.

- 짧게 누르기: 문자 또는 기본 기능
- 길게 누르기: 보조키나 다른 기능

모든 키가 두 가지 동작을 갖는 것은 아닙니다. 출고 키맵에 함께 표시된 키만 해당합니다.

## 처음 확인하는 순서

1. 키보드를 유선 또는 블루투스로 연결합니다.
2. 메모장처럼 입력 결과를 바로 볼 수 있는 화면을 엽니다.
3. 문자 키를 한 개씩 짧게 눌러 기본 입력을 확인합니다.
4. `Shift`, `Ctrl`, `Alt`, `Windows` 또는 `Command` 등 보조키를 확인합니다.
5. 키맵에 레이어가 있다면 레이어 키를 누른 상태에서 해당 기능을 확인합니다.
6. 예상과 다른 키는 위치와 실제 입력 결과를 기록합니다.

한 번에 여러 키를 확인하기보다, 기본 문자 → 보조키 → 레이어 순서로 나누어 확인하면 원인을 찾기 쉽습니다.

## 예상과 다른 문자가 입력될 때

키보드 문제처럼 보여도 운영체제의 입력 설정 때문에 문자가 다르게 나올 수 있습니다.

먼저 아래 내용을 확인해 주세요.

- 한글과 영문 입력 상태
- 운영체제의 키보드 배열
- Windows와 macOS의 보조키 차이
- 사용 중인 프로그램의 자체 단축키
- 입력 언어가 두 개 이상 등록되어 있는지

특정 프로그램에서만 문제가 생기면 메모장이나 브라우저 주소창에서도 같은지 확인해 주세요.

## 한 키만 입력되지 않을 때

1. 유선 연결에서도 같은 키가 입력되지 않는지 확인합니다.
2. 다른 PC나 휴대폰에서도 같은지 확인합니다.
3. 키맵에서 해당 위치가 현재 레이어에서 실제 키로 지정되어 있는지 확인합니다.
4. 키를 눌렀을 때 매번 안 되는지, 가끔 안 되는지 기록합니다.
5. 가능하면 문제가 보이도록 짧은 영상을 촬영합니다.

키캡, 스위치 또는 내부 부품을 분리하기 전에는 먼저 문의해 주세요. 임의 분해는 증상 확인을 어렵게 만들 수 있습니다.

## 여러 키가 동시에 이상할 때

- 특정 줄이나 한쪽 영역만 안 되는지 확인합니다.
- 유선과 블루투스에서 같은 증상인지 확인합니다.
- 재부팅한 다른 기기에서도 같은지 확인합니다.
- 키맵과 실제 배열이 서로 다른 출고본인지 확인합니다.

여러 기기와 연결 방식에서 같은 영역의 키가 반복해서 동작하지 않으면 A/S 확인이 필요할 수 있습니다.

## 설정을 바꾸기 전에

전체 초기화나 펌웨어 변경은 현재 설정과 연결 기록을 바꿀 수 있습니다.

공식 안내를 받기 전에는 다음 작업을 권하지 않습니다.

- 출처를 확인하지 않은 펌웨어 설치
- 전체 설정 초기화
- 키보드 분해
- 내부 케이블이나 부품 재결합

먼저 현재 키맵과 증상을 기록한 뒤 문의해 주세요.

## 문의할 때 보내면 좋은 정보

- 주문 정보와 제품명
- 사용 중인 운영체제
- 유선 또는 블루투스 연결 여부
- 예상한 키 동작과 실제 입력 결과
- 문제가 생기는 키의 위치
- 항상 발생하는지, 가끔 발생하는지
- 다른 기기에서도 같은지
- 증상을 확인할 수 있는 사진 또는 영상

출고 키맵을 찾지 못했거나 현재 배열과 맞지 않는다면 [A/S 문의 안내](/user-guide/after-service/)에 따라 주문 정보와 함께 문의해 주세요.
