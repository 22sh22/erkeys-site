# 기본 키 설정 및 사용법

MODU-C V1의 기본 키맵과 Lower 레이어를 확인하는 페이지입니다.

## MODU-C V1 기본 키맵

아래 이미지는 MODU-C V1 펌웨어의 기본 키맵입니다.

![MODU-C 기본 레이어 키맵](/user-guide/key-settings/modu-c-default-layer.png)

![MODU-C Lower 레이어 키맵](/user-guide/key-settings/modu-c-lower-layer.png)

Lower 키를 누르고 있는 동안 보조 레이어가 활성화됩니다. 회색 키는 기본 레이어의 동작을 그대로 사용합니다. 추가 B키 모듈이 장착된 제품은 N키 왼쪽의 별도 B키를 사용할 수 있습니다. 외측 트랙볼 장착 제품은 엄지키 순서가 이미지 하단의 대체 배치로 바뀝니다.

## 입력 확인

키 입력 반응을 직접 확인하려면 [MODU-C 키 테스트](/key-test/)를 열어보세요.

## 문제가 있을 때

키 입력이 이미지와 다르거나 일부 키가 동작하지 않으면 [A/S 문의 안내](/user-guide/after-service/)를 확인해 주세요.
