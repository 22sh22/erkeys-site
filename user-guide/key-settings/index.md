# 기본 키 세팅 및 사용법

ERKEYS 제품의 기본 키 세팅과 주요 사용법을 정리하는 페이지입니다.

## 기본 사용

- 제품을 연결한 뒤 기본 입력이 정상 동작하는지 확인합니다.
- 운영체제의 키보드 입력 언어와 배열 설정을 확인합니다.
- 자주 사용하는 기능키나 조합키는 실제 사용 환경에 맞춰 안내를 추가합니다.

## 키 세팅 확인

1. 연결된 기기에서 텍스트 입력 화면을 엽니다.
2. 주요 키가 예상대로 입력되는지 확인합니다.
3. 특수키, 기능키, 조합키를 차례로 확인합니다.

## 사용 중 참고사항

- OS별 키 동작이 다를 수 있습니다.
- 일부 기능은 연결 방식이나 기기 설정에 따라 다르게 동작할 수 있습니다.
- 세부 키맵 안내는 추후 확정된 내용으로 업데이트합니다.

내용은 실제 제품 기준으로 추후 업데이트됩니다.
