# 블루투스, 무선 연결 방법

ERKEYS 제품의 블루투스 또는 무선 연결 방법을 정리하는 페이지입니다.

## 연결 전 확인

- 기기의 전원이 켜져 있는지 확인합니다.
- 배터리 잔량이 충분한지 확인합니다.
- 연결하려는 PC, 태블릿, 휴대폰의 블루투스 기능을 켭니다.

## 기본 연결 순서

1. 키보드를 페어링 모드로 전환합니다.
2. 기기의 블루투스 설정 화면을 엽니다.
3. 표시되는 ERKEYS 장치를 선택합니다.
4. 연결이 완료되면 입력이 정상 동작하는지 확인합니다.

## 연결이 되지 않을 때

- 기존에 등록된 장치를 삭제한 뒤 다시 연결합니다.
- 키보드와 연결 기기를 가까운 위치에 둡니다.
- 다른 기기에 이미 연결되어 있는지 확인합니다.

내용은 실제 제품 기준으로 추후 업데이트됩니다.
