# 블루투스·무선 연결 방법

MODU-C가 기기에 연결되지 않거나, 기존 연결이 불안정할 때 확인할 내용입니다.

## 먼저 확인할 것

- 키보드 전원이 켜져 있는지 확인합니다.
- 배터리가 부족할 수 있으므로 충분히 충전한 뒤 다시 시도합니다.
- 연결할 기기의 블루투스가 켜져 있는지 확인합니다.
- 이전에 연결했던 다른 기기가 가까이 있다면 해당 기기의 블루투스를 잠시 꺼둡니다.

## 처음 연결할 때

출고 키맵에서 블루투스 관련 키 위치를 확인한 뒤, 연결할 기기의 블루투스 설정에서 새 장치 추가를 진행합니다.

키 위치를 모르겠다면 여러 키를 임의로 누르기보다 [기본 키 설정 및 사용법](/user-guide/key-settings/)을 먼저 확인해 주세요.

## 다시 연결되지 않을 때

1. 기기의 블루투스 목록에서 기존 MODU-C 등록을 삭제합니다.
2. 기기의 블루투스를 껐다가 다시 켭니다.
3. 키보드를 다시 연결 대기 상태로 둡니다.
4. 새 장치로 다시 등록합니다.

기존 등록을 삭제한 뒤에는 자동으로 다시 연결되지 않습니다. 새 장치 추가 과정이 필요합니다.

## 계속 문제가 있을 때

다른 기기에서도 같은 증상이 생기는지 확인해 주세요. 여러 기기에서 같은 문제가 반복되면 [A/S 문의 안내](/user-guide/after-service/)를 확인해 주세요.
