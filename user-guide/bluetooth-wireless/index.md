# 블루투스·무선 연결 방법

처음 연결할 때와 기존 연결이 되지 않을 때의 확인 순서입니다.

출고 시 적용된 키맵에 따라 블루투스 관련 키의 위치가 다를 수 있습니다. 제품과 함께 받은 키맵이나 안내 자료가 있다면 먼저 준비해 주세요.

## 연결 전 확인

- 키보드의 전원이 켜져 있는지 확인합니다.
- 배터리가 부족할 수 있으므로 충분히 충전한 뒤 다시 시도합니다.
- 연결할 PC, 태블릿 또는 휴대폰의 블루투스가 켜져 있는지 확인합니다.
- 이전에 연결했던 다른 기기가 가까이 있다면 해당 기기의 블루투스를 잠시 꺼둡니다.
- 가능하면 유선 연결에서 기본 입력이 되는지도 확인합니다.

유선 입력은 되지만 블루투스만 되지 않는다면, 키 입력 자체보다 무선 연결 설정을 먼저 확인하면 됩니다.

## 처음 연결하기

1. 출고 키맵에서 `Bluetooth`, `BT` 또는 무선 연결로 표시된 키를 찾습니다.
2. 사용할 블루투스 슬롯을 선택해 키보드가 새 연결을 기다리는 상태로 전환합니다.
3. 연결할 기기에서 블루투스 설정의 새 장치 추가 화면을 엽니다.
4. 새 장치 목록에 나타난 키보드를 선택합니다.
5. 연결 후 메모장이나 검색창에서 입력이 되는지 확인합니다.

블루투스 키나 슬롯 위치를 찾을 수 없다면 여러 키를 임의로 누르기보다, 주문 정보와 함께 A/S 문의로 출고 키맵을 요청해 주세요.

## 등록되어 있지만 연결되지 않을 때

아래 순서대로 한 단계씩 확인해 주세요.

1. 키보드를 충분히 충전합니다.
2. 이전에 연결했던 다른 기기의 블루투스를 잠시 끕니다.
3. 현재 기기의 블루투스 목록에서 기존 키보드 등록을 삭제합니다.
4. 기기의 블루투스를 껐다가 다시 켭니다.
5. 키보드에서 사용할 블루투스 슬롯을 다시 선택합니다.
6. 새 장치로 다시 등록합니다.

기존 등록을 삭제한 뒤에는 자동으로 다시 연결되지 않습니다. 새 장치 추가 과정이 필요합니다.

## 연결은 되지만 입력이 끊길 때

- 키보드와 연결 기기를 가까이 두고 다시 확인합니다.
- USB 허브나 무선 공유기 등 주변 장치에서 거리를 두고 확인합니다.
- 같은 장소에서 다른 PC나 휴대폰에도 같은 증상이 생기는지 확인합니다.
- 충전 케이블을 분리한 상태와 연결한 상태를 각각 확인합니다.
- 특정 기기에서만 문제가 생기면 해당 기기의 블루투스 등록을 삭제하고 다시 연결합니다.

여러 기기에서 같은 증상이 반복되면 키보드 쪽 확인이 필요할 수 있습니다.

## 문의 전에 확인할 내용

- 연결하려는 기기와 운영체제
- 처음 연결인지, 이전에는 연결됐는지
- 블루투스 목록에 키보드가 표시되는지
- 표시되지만 연결이 실패하는지, 연결 후 입력이 끊기는지
- 유선 연결에서는 입력이 되는지
- 다른 기기에서도 같은 증상이 생기는지
- 사용한 블루투스 슬롯
- 이미 시도한 방법

## 자주 묻는 질문

### 블루투스 목록에 키보드가 보이지 않습니다

충전 상태와 전원을 먼저 확인한 뒤, 다른 기기에 이미 연결되어 있지 않은지 확인해 주세요. 이후 사용할 블루투스 슬롯을 다시 선택하고 새 장치 검색을 실행합니다.

### 목록에는 보이지만 연결에 실패합니다

기기에 저장된 기존 등록을 삭제한 뒤 새 장치로 다시 등록해 주세요. 같은 이름의 항목이 여러 개 있다면 기존 항목을 모두 정리한 뒤 다시 시도하는 편이 좋습니다.

### 연결 기록을 모두 초기화해도 되나요?

출고 키맵과 초기화 방법을 정확히 확인하기 전에는 전체 초기화나 펌웨어 변경을 권하지 않습니다. 먼저 기존 장치 등록 삭제와 재연결까지만 시도해 주세요.

그래도 해결되지 않으면 [A/S 문의 안내](/user-guide/after-service/)에 따라 증상과 확인 결과를 보내주세요.
