# A/S 관련 문의

ERKEYS 제품 사용 중 A/S가 필요한 경우 확인할 내용을 정리하는 페이지입니다.

## 문의 전 확인

- 제품명 또는 모델명을 확인합니다.
- 구매 시기와 구매처를 확인합니다.
- 문제가 발생한 상황을 간단히 정리합니다.
- 가능하면 증상을 확인할 수 있는 사진이나 영상을 준비합니다.

## 문의 시 포함하면 좋은 내용

- 이름 또는 연락 가능한 정보
- 제품 정보
- 증상 설명
- 발생 시점
- 이미 시도해 본 해결 방법

## 접수 방식

A/S 관련 문의는 추후 제공되는 구글폼 또는 공식 문의 경로를 통해 접수합니다.

정확한 접수 링크와 정책은 추후 업데이트됩니다.
