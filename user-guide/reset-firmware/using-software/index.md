# 단축키로 펌웨어 초기화하기

<img width="512" height="512" alt="image" src="https://github.com/user-attachments/assets/4ea583eb-c1be-4704-a77c-69419f46afb7" />

- 우측 초기화 >> layer1 키 + 좌측 Ctrl 키 + 5
- 좌측 초기화 >> layer1 키 + 좌측 Ctrl 키 + 6

본 동작은 펌웨어 버전 v3 이상(9월 14일 이후 출고분)부터 사용하실 수 있습니다.

이전 버전은 [리셋 버튼을 이용한 방법](/user-guide/reset-firmware/using-button/)을 참고하세요.
