# 리셋 및 펌웨어 교체

리셋이나 펌웨어 교체는 일반 연결 확인보다 실수 가능성이 높습니다.

먼저 전원, USB 포트, 기존 블루투스 등록 삭제를 확인한 뒤 진행해 주세요.

최신 펌웨어 다운로드 : [링크](https://github.com/22sh22/modu-c-zmk-config/releases/tag/firmware)

## 방법

### 1. 부트로더 진입

- 2026년 9월 14일 이후 배송 >> [단축키를 이용한 리셋 방법](/user-guide/reset-firmware/using-software)
- 2026년 9월 14일 이전 배송 >> [물리 버튼을 이용한 리셋 방법](/user-guide/reset-firmware/using-button)

### 2. 펌웨어 적용

1. 안내받은 `.uf2` 파일을 `MODU_BOOT` 드라이브에 넣습니다.
2. 파일 복사가 끝나면 제품이 자동으로 재부팅됩니다.

`MODU_BOOT` 드라이브가 나타나지 않으면 케이블을 바꿔 다시 시도해 주세요. 충전 전용 케이블은 펌웨어 교체에 사용할 수 없습니다.

## 주의사항

- 사이드 커버를 열 때 과도한 힘을 가하지 마세요.
- 펌웨어 파일 이름이 좌측용인지 우측용인지 확인한 뒤 넣어 주세요.
- 좌측용과 우측용 펌웨어를 서로 바꿔 넣으면 정상 동작하지 않을 수 있습니다.
- 리셋 후에는 기존 블루투스 등록을 삭제하고 새로 연결해야 할 수 있습니다.

펌웨어 교체 후에도 같은 문제가 반복되면 [A/S 문의 안내](/user-guide/after-service/)를 확인해 주세요.
