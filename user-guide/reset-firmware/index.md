# 리셋 및 펌웨어 교체

리셋이나 펌웨어 교체는 일반 연결 확인보다 실수 가능성이 높습니다.

먼저 전원, USB 포트, 기존 블루투스 등록 삭제를 확인한 뒤 진행해 주세요.

## 먼저 해볼 것

- 연결할 기기에서 기존 MODU-C 블루투스 등록을 삭제합니다.
- MODU-C를 다시 연결 대기 상태로 둔 뒤 새 장치로 등록합니다.
- USB 연결 문제라면 데이터 전송이 가능한 케이블로 다시 연결합니다.
- PC 입력용 연결은 좌측 키보드 USB 포트를 먼저 사용합니다.

## 부트로더 진입

펌웨어 파일을 다시 넣으려면 사이드 커버를 열고 PCB의 리셋 버튼을 눌러야 합니다.

사이드 커버를 탈착할 때 과도한 힘을 가하면 커버나 결합부가 파손될 수 있습니다. 천천히 힘을 나누어 열어 주세요.

1. MODU-C를 USB 케이블로 PC에 연결합니다.
2. 사이드 커버를 조심해서 분리합니다.
3. PCB의 리셋 버튼을 빠르게 두 번 누릅니다.
4. PC에 `MODU_BOOT` 드라이브가 나타나는지 확인합니다.
5. 안내받은 `.uf2` 파일을 `MODU_BOOT` 드라이브에 넣습니다.
6. 파일 복사가 끝나면 제품이 자동으로 재부팅됩니다.

`MODU_BOOT` 드라이브가 나타나지 않으면 케이블을 바꿔 다시 시도해 주세요. 충전 전용 케이블은 펌웨어 교체에 사용할 수 없습니다.

## 블루투스 연결 정보를 초기화할 때

블루투스 연결 정보 초기화가 필요한 경우에는 설정 초기화용 UF2를 사용할 수 있습니다.

설정 초기화용 UF2는 좌측과 우측에 모두 사용할 수 있는 파일입니다. 안내받은 파일을 `MODU_BOOT` 드라이브에 넣은 뒤, 다시 일반 펌웨어를 넣어 사용합니다.

## 주의할 것

- 사이드 커버를 열 때 과도한 힘을 가하지 마세요.
- 펌웨어 파일 이름이 좌측용인지 우측용인지 확인한 뒤 넣어 주세요.
- 좌측용과 우측용 펌웨어를 서로 바꿔 넣으면 정상 동작하지 않을 수 있습니다.
- 리셋 후에는 기존 블루투스 등록을 삭제하고 새로 연결해야 할 수 있습니다.

펌웨어 교체 후에도 같은 문제가 반복되면 [A/S 문의 안내](/user-guide/after-service/)를 확인해 주세요.
