# 리셋 및 펌웨어 교체

리셋이나 펌웨어 교체는 일반 연결 확인보다 실수 가능성이 높습니다.

먼저 전원, USB 포트, 기존 블루투스 등록 삭제를 확인한 뒤 진행해 주세요.

## 먼저 확인할 것

- 전원이 켜져 있는지 또는 연결 방식에 맞게 꺼져 있는지
- PC 연결용 USB 포트를 사용했는지
- 데이터 전송이 가능한 케이블을 사용했는지
- 기존 블루투스 등록을 삭제한 뒤 다시 연결해 봤는지
- 다른 PC 또는 기기에서도 같은 증상이 있는지

## 현재 정리할 내용

- 리셋 버튼 위치
- 리셋 진입 방법
- 펌웨어 교체가 필요한 상황
- 펌웨어 파일을 넣는 방법
- 교체 후 정상 연결 확인 방법

정확한 절차가 확정되면 이 페이지에 단계별로 정리합니다.

안내 없이 제품을 분해하거나 임의로 펌웨어를 변경하는 것은 권하지 않습니다.
