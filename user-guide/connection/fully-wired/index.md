# 완전히 유선으로 연결하기

배터리 걱정 없이 케이블 연결 상태로 사용하는 방법입니다.

## 이렇게 연결합니다

유선 사용 방식은 실제 연결 기준 확인 후 정리합니다.

현재 확인할 내용입니다.

- 양쪽 키보드를 모두 PC에 연결해야 하는지
- 좌측 키보드만 PC에 연결하면 되는지
- 전원 스위치를 켜야 하는지, 꺼야 하는지
- 어떤 USB 포트를 PC와 연결해야 하는지
- 유선 연결 시 LED가 어떤 상태여야 정상인지

## 먼저 확인할 것

유선 연결이 되지 않는다면 아래 내용을 먼저 확인해 주세요.

- 케이블이 데이터 전송을 지원하는지
- PC의 다른 USB 포트에서도 같은지
- [USB 포트 역할](/user-guide/usb-ports/)에서 PC 연결용 포트를 확인했는지

정확한 연결 절차가 확정되면 이 페이지에 짧은 순서로 정리합니다.
