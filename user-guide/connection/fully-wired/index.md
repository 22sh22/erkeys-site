# 완전히 유선으로 연결하기

완전히 유선으로 사용하려면 좌우 키보드가 유선 split용 펌웨어 상태여야 합니다.

출고 상태에서 바로 연결해 사용하는 일반 방식은 [한쪽 유선으로 연결하기](/user-guide/connection/half-wired/)를 먼저 확인해 주세요.

## 이렇게 연결합니다

1. 좌우 키보드를 유선 split 케이블로 연결합니다.
2. 좌측 키보드를 PC와 USB로 연결합니다.
3. 양쪽 키보드 LED가 흰색으로 켜지는지 확인합니다.
4. 양쪽 키 입력이 정상적으로 되는지 확인합니다.

## 정상 상태는 이렇습니다

| 확인 위치 | 정상 상태 | 의미 |
| --- | --- | --- |
| 좌측 키보드 | 흰색 LED | PC와 USB로 연결된 상태 |
| 우측 키보드 | 흰색 LED | 유선 split으로 연결된 상태 |

## 안 될 때는 이것만 확인하세요

- 좌우를 연결하는 케이블이 제대로 꽂혀 있는지 확인합니다.
- 좌측 키보드가 PC와 USB로 연결되어 있는지 확인합니다.
- 데이터 전송이 가능한 USB 케이블을 사용했는지 확인합니다.
- 양쪽 모두 유선 split용 펌웨어 상태인지 확인합니다.

일반 출고 상태에서 완전 유선 연결이 되지 않는다면 먼저 [한쪽 유선으로 연결하기](/user-guide/connection/half-wired/) 방식으로 사용해 주세요.
