# 유·무선 연결 방법

사용하려는 연결 방식을 선택해 주세요.

- [무선으로 연결하기](/user-guide/connection/wireless/)  
  PC와 케이블로 연결하지 않고 양쪽 키보드를 무선으로 사용합니다.

- [한쪽 유선으로 연결하기](/user-guide/connection/half-wired/)  
  PC와는 유선으로 연결하고, 좌우 키보드 사이는 무선으로 사용합니다.

- [완전히 유선으로 연결하기](/user-guide/connection/fully-wired/)  
  배터리 걱정 없이 케이블 연결 상태로 사용합니다.

포트 위치가 헷갈린다면 [USB 포트 역할](/user-guide/usb-ports/)을 먼저 확인해 주세요.
