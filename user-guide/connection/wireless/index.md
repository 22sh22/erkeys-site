# 완전히 무선으로 연결하기

PC와 케이블로 연결하지 않은 상태에서 MODU-C를 사용하는 방법입니다.

## 이렇게 연결합니다

1. PC와 연결된 케이블이 있다면 모두 분리합니다.
2. 좌측 키보드와 우측 키보드의 전원을 모두 켭니다.
3. 좌측 키보드에서 사용할 블루투스 프로파일을 선택합니다.
4. 연결할 기기에서 블루투스 설정을 열고 MODU-C를 선택합니다.
5. 우측 키보드 LED가 파란색으로 켜지는지 확인합니다.
6. 양쪽 키 입력이 정상적으로 되는지 확인합니다.

블루투스 프로파일 선택과 초기화 키 위치는 [기본 키 설정 및 사용법](/user-guide/key-settings/)에서 확인할 수 있습니다.

## 좌측 LED 확인

좌측 LED는 선택된 블루투스 프로파일과 페어링 상태를 보여줍니다.

| 블루투스 프로파일 | LED 색상 | 천천히 깜빡이는 경우 | 계속 켜져 있는 경우 |
| --- | --- | --- | --- |
| 프로파일 1 | 민트색 | 새 기기 연결 대기 중 | 저장된 기기와 다시 연결 가능한 상태 |
| 프로파일 2 | 연보라색 | 새 기기 연결 대기 중 | 저장된 기기와 다시 연결 가능한 상태 |
| 프로파일 3 | 주황색 | 새 기기 연결 대기 중 | 저장된 기기와 다시 연결 가능한 상태 |

좌측 LED가 흰색이면 USB 전원이 감지된 상태입니다. 완전히 무선으로 사용하려면 PC와 연결된 케이블을 분리해 주세요.

## 우측 LED 확인

우측 LED는 좌측 키보드와의 연결 상태를 보여줍니다.

| 우측 LED 상태 | 의미 | 다음 행동 |
| --- | --- | --- |
| 파란색 빠른 깜빡임 | 좌측 키보드와 아직 연결 준비가 되지 않음 | 양쪽 전원이 켜져 있는지 확인 |
| 빨간색 | 좌측 키보드와 아직 연결되지 않음 | 잠시 기다린 뒤 양쪽 전원을 다시 켜기 |
| 파란색 | 좌측 키보드와 연결됨 | 양쪽 키 입력 확인 |

전원을 켠 직후에는 LED가 잠시 빨간색으로 보일 수 있습니다.

## 안 될 때는 이것만 확인하세요

- 좌측과 우측 전원이 모두 켜져 있는지 확인합니다.
- 연결할 기기에서 기존 MODU-C 등록을 삭제한 뒤 다시 연결합니다.
- 다른 기기에 이미 연결되어 있다면 해당 기기의 블루투스를 잠시 꺼둡니다.
- 우측 LED가 파란색으로 바뀌지 않으면 좌우 연결 상태를 먼저 확인합니다.

계속 해결되지 않으면 [알려진 문제와 해결 방법](/user-guide/known-issues/)을 확인해 주세요.
