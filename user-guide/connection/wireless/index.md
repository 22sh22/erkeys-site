# 완전히 무선으로 연결하기

PC와 케이블로 연결하지 않은 상태에서 MODU-C를 사용하는 방법입니다.

## 이렇게 연결합니다

1. PC와 연결된 케이블이 있다면 모두 분리합니다.
2. 좌측 키보드와 우측 키보드의 전원을 모두 켭니다.
3. 좌측 키보드의 LED 상태를 확인합니다.
4. 우측 키보드의 LED가 빨간 불에서 파란 불로 바뀌는지 확인합니다.
5. 연결할 기기에서 MODU-C를 선택해 입력이 되는지 확인합니다.

## 좌측 LED 확인

| 블루투스 프로파일 | LED 색상 | 깜빡이는 경우 | 계속 켜져 있는 경우 |
| --- | --- | --- | --- |
| 프로파일 1 | 확인 필요 | 연결 대기 또는 연결 시도 중 | 연결 완료 |
| 프로파일 2 | 확인 필요 | 연결 대기 또는 연결 시도 중 | 연결 완료 |
| 프로파일 3 | 확인 필요 | 연결 대기 또는 연결 시도 중 | 연결 완료 |

## 우측 LED 확인

| 우측 LED 상태 | 의미 | 다음 행동 |
| --- | --- | --- |
| 빨간 불 | 좌측 키보드와 아직 연결되지 않음 | 양쪽 전원이 켜져 있는지 확인 |
| 파란 불 | 좌측 키보드와 연결됨 | 양쪽 키 입력을 확인 |

## 안 될 때는 이것만 확인하세요

- 좌측과 우측 전원이 모두 켜져 있는지 확인합니다.
- 연결할 기기에서 기존 MODU-C 등록을 삭제한 뒤 다시 연결합니다.
- 다른 기기에 이미 연결되어 있다면 해당 기기의 블루투스를 잠시 꺼둡니다.
- 우측 LED가 계속 빨간 불이면 좌우 연결 상태를 먼저 확인합니다.

계속 해결되지 않으면 [알려진 문제와 해결 방법](/user-guide/known-issues/)을 확인해 주세요.
