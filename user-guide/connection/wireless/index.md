# 무선으로 연결하기

PC와 케이블로 연결하지 않은 상태에서 MODU-C를 사용하는 방법입니다.

## 이렇게 연결합니다

1. PC와 연결된 케이블을 모두 분리합니다.
2. 좌,우 키보드의 전원을 모두 켭니다.
3. 좌측 키보드의 LED를 확인합니다.
4. 연결할 기기에서 블루투스 설정을 열고 `Modu`를 선택합니다.

## 좌측 LED 확인

좌측 LED는 선택된 블루투스 프로파일과 페어링 상태를 보여줍니다.

| LED 색상 | 깜빡이는 경우 | 계속 켜져 있는 경우 |
| --- | --- | --- |
| 흰색(밝은 연두) | - | 유선 연결됨 |
| 민트색 | 프로파일 1번 연결 준비됨 | 프로파일 1번 페어링됨 |
| 연보라색 | 프로파일 2번 연결 준비됨 | 프로파일 2번 페어링됨 |
| 주황색 | 프로파일 3번 연결 준비됨 | 프로파일 3번 페어링됨 |
| 초록색 | - | 펌웨어 초기화됨 |

깜빡이지 않는다면 이미 어딘가에 페어링되어 연결할 수 없는 상태입니다.
이럴 때는, 해당 프로파일을 초기화하면 해결할 수 있습니다.

### 기본 조작법 중 블루투스 관련
- 블루투스 프로파일 초기화: 레이어 키 + shift
- 블루투스 프로파일 전환: 레이어 키 + z,x,c

상세한 키매핑은 [기본 키 설정 및 사용법](/user-guide/key-settings/)에서 확인할 수 있습니다.

## 우측 LED 확인

우측 LED는 좌측 키보드와의 연결 상태를 보여줍니다.

| 우측 LED 상태 | 의미 |
| --- | --- |
| 빨간색 | 리셋 중, 좌측 키보드와 아직 연결되지 않음 |
| 파란색 | 좌측 키보드와 연결됨 |
| 초록색 | 펌웨어 초기화됨 |

전원을 켠 직후에는 LED가 잠시 빨간색으로 빛납니다.

## 안 될 때는 이것만 확인하세요

- MODU-C는 좌측이 기준입니다. 좌측 없이 우측은 사용할 수 없습니다.
- 연결할 기기에서 기존 MODU-C 등록을 삭제한 뒤 다시 연결합니다.
- LED가 깜빡이지 않는다면, 블루투스 초기화를 진행해주세요.

계속 해결되지 않으면 [알려진 문제와 해결 방법](/user-guide/known-issues/)을 확인해 주세요.
