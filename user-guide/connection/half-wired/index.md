# 한쪽 유선으로 연결하기

PC와는 유선으로 연결하고, 좌우 키보드 사이는 무선으로 사용하는 방법입니다.

## 이렇게 연결합니다

1. 좌측 키보드는 전원을 끈 채 둡니다.
2. 우측 키보드의 전원을 켭니다.
3. 좌측 키보드의 바깥쪽 USB 포트를 PC와 연결합니다.
4. 우측 키보드가 좌측 키보드와 연결되는지 확인합니다.
5. 우측 LED가 파란 불로 바뀌면 양쪽 키 입력을 확인합니다.

## 정상 상태는 이렇습니다

| 확인 위치 | 정상 상태 | 의미 |
| --- | --- | --- |
| 좌측 키보드 | PC와 USB 연결됨 | PC 입력을 담당 |
| 우측 키보드 | 파란 불 | 좌측 키보드와 연결됨 |

## 안 될 때는 이것만 확인하세요

- 좌측 키보드 전원이 꺼져 있는지 확인합니다.
- 우측 키보드 전원이 켜져 있는지 확인합니다.
- 좌측 바깥쪽 USB 포트에 연결했는지 확인합니다.
- 우측 LED가 계속 빨간 불이면 우측 전원을 껐다가 다시 켭니다.

포트 위치가 헷갈리면 [USB 포트 역할](/user-guide/usb-ports/)을 확인해 주세요.
