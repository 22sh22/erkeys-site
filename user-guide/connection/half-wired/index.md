# 한쪽 유선으로 연결하기

PC와는 유선으로 연결하고, 좌우 키보드 사이는 무선으로 사용하는 방법입니다.

## 이렇게 연결합니다

1. 좌측 키보드는 전원을 끈 채 둡니다.
2. 우측 키보드의 전원을 켭니다.
3. 좌측 키보드의 바깥쪽 USB 포트를 PC와 연결합니다.
4. 좌측 키보드 LED가 흰색으로 켜지는지 확인합니다.
5. 우측 키보드 LED가 녹색으로 켜지는지 확인합니다.
6. 양쪽 키 입력이 정상적으로 되는지 확인합니다.

## 정상 상태는 이렇습니다

| 확인 위치 | 정상 상태 | 의미 |
| --- | --- | --- |
| 좌측 키보드 | 흰색 LED | PC와 USB로 연결된 상태 |
| 우측 키보드 | 녹색 LED | 좌측 키보드와 연결된 상태 |

## 안 될 때는 이것만 확인하세요

- 좌측 키보드 전원이 꺼져 있는지 확인합니다.
- 우측 키보드 전원이 켜져 있는지 확인합니다.
- 좌측 바깥쪽 USB 포트에 연결했는지 확인합니다.
- 우측 LED가 녹색으로 바뀌지 않으면 우측 전원을 껐다가 다시 켭니다.

포트 위치가 헷갈리면 [USB 포트 역할](/user-guide/usb-ports/)을 확인해 주세요.
